# ── Deliberately NOT installed: PaddleOCR ─────────────────────────────────
# The OCR layer falls back to Tesseract automatically when PaddleOCR is
# absent, and Tesseract is what this app has actually been tuned against —
# the small-type upscale, the core-line-height measurement and the debris
# filter in modules/ocr_engine.py were all measured on Tesseract output.
#
# Do not add paddleocr/paddlepaddle to this file for a Community Cloud
# deployment. Between them they pull well over a gigabyte of wheels plus
# model weights downloaded at first use, which will exhaust the container
# before the app finishes starting.
#
# To try it on a local machine (Python 3.9–3.12 only):
#   pip install paddleocr paddlepaddle
